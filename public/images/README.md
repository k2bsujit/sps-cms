# SP Surya PDF Quotation Assets & Images Guide

Place your company logo and solar images in this folder (`public/images/`) to automatically include them in the generated 6-Page PDF Quotation:

---

## 🖼 Image File Names & Usage in PDF:

| File Name | Placement in 6-Page PDF | Recommended Format / Size |
| :--- | :--- | :--- |
| **`sp-surya-logo.png`** *(or `logo.png`)* | **Top-Left Circular Logo Header** on all pages (Pages 1 to 6) | Transparent PNG (approx. 250×250 px) |
| **`rooftop-house.png`** *(or `rooftop-house.jpg`, `house.png`)* | **Page 1 Main Solar House Banner** (between customer details and the green banner) | High-Res PNG / JPG (approx. 1200×450 px) |

---

> [!NOTE]
> If any image file is not present in this folder, the system **automatically and gracefully renders a clean, styled placeholder** without breaking the PDF build. Once you place the file, the real image will appear immediately on the next PDF download!
